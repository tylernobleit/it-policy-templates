# Employee Onboarding and Offboarding Checklist

**Employee:** [NAME]  **Role:** [ROLE]  **Manager:** [NAME]
**Start / last day:** [DATE]  **Ticket:** [#]

## Onboarding

### Before day one

- [ ] Manager supplies: role, required systems, groups/permissions (copy from a similar role)
- [ ] Device prepared (see the new PC setup checklist) and recorded in the asset inventory
- [ ] Accounts created: directory/email, [LINE-OF-BUSINESS APPS], VPN/remote access if needed
- [ ] Group memberships and shared mailboxes granted (least privilege)
- [ ] MFA enrolment scheduled for first login
- [ ] Phone, headset, building access arranged
- [ ] Licences assigned and recorded

### Day one

- [ ] Hand over device and credentials securely (temporary password, forced change at first login)
- [ ] MFA set up with the user present
- [ ] Walk through the Acceptable Use Policy; signed acknowledgement collected
- [ ] Show how to report problems and where files live
- [ ] Printers, mapped drives and email confirmed working

### First week

- [ ] Follow-up check: anything missing or too much access?

## Offboarding

### Planned departure (prepare in advance)

- [ ] Last day and time confirmed with HR/manager
- [ ] Decide who receives the mailbox, files and any shared documents
- [ ] Inventory of company devices, keys, cards and accounts to be returned
- [ ] Knowledge transfer completed for work only this person handled

### On the last day (or immediately for involuntary departures)

- [ ] Disable the account and revoke active sessions
- [ ] Reset the password and remove MFA methods and registered devices
- [ ] Remove from groups; save group list to the ticket first (so it can be restored if needed)
- [ ] Convert mailbox to shared or delegate access to the manager; set auto-reply if appropriate
- [ ] Forward email as agreed with the manager for a defined period
- [ ] Remove access to line-of-business apps, VPN, cloud services and shared passwords the person knew
- [ ] Rotate any shared credentials the person had access to
- [ ] Wipe or retrieve mobile devices with company data
- [ ] Collect company devices; verify serial numbers against the inventory

### After

- [ ] Devices securely wiped, reimaged or retired; recorded in inventory
- [ ] Licences reclaimed or reassigned
- [ ] Account deleted after the agreed retention period (for example 30 to 90 days) once data has been moved
- [ ] Ticket closed with date, who did what, and any exceptions
